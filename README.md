# Атлас мира

Интерактивная карта: современные страны, история государств с 4000 г. до н. э., войны со стрелками ударов, ресурсы, ветры и океанские течения. Плоская проекция и глобус.

## Запуск на своём домене

1. Соберите сайт с адресом домена: `SITE_URL=https://ваш-домен.ru sh tools/build.sh` (создаёт `index.html`, `robots.txt`, `sitemap.xml`).
2. Заполните `config.js`: адрес приёма сообщений, почту, номер Метрики, идентификатор рекламного блока. Пустое значение отключает функцию.
3. Замените выделенные поля в квадратных скобках в `privacy.html` и `about.html`.
4. Загрузите на хостинг: `index.html`, `privacy.html`, `about.html`, `config.js`, `favicon.svg`, `favicon.png`, `og.jpg`, `robots.txt`, `sitemap.xml`, папки `data`, `vendor`, `fonts`.

Локальная проверка: `python3 -m http.server 8000` и открыть http://localhost:8000/.

## Обновление сайта

На хостинге раз в час выполняется `~/update-atlas.sh`: он забирает свежую версию из ветки `main` на GitHub. Файлы сайта на хостинге вручную не правятся — все изменения идут через репозиторий.

## Метрика и реклама

Номер счётчика и блоки РСЯ задаются в `config.js`. Главная подключает их сама, текстовые страницы — через `services.js`: счётчик с Вебвизором и рекламный блок внизу статьи (`adBlockIdText`, иначе `adBlockId`). Всё включается после согласия посетителя на cookie, выбор общий для всего сайта.

## IndexNow (быстрая индексация в Яндексе)

Ключ — файл `7f80a98a7e36b5b475a38bdb944e4af6.txt` в корне сайта. Когда изменения уже на хостинге, отправьте адреса: GitHub → Actions → «IndexNow» → Run workflow, или `python3 tools/indexnow.py` (весь sitemap) / `python3 tools/indexnow.py strany/indiya/` (выбранные страницы).

## Сообщения о неточностях

Форма отправляет их в `feedback.php`. Каждое сообщение дописывается в `~/atlas-feedback.log` (вне папки сайта). Чтобы получать копии на почту, создайте на хостинге файл `~/atlas-feedback.ini` со строкой `email = ваш@адрес`.

## Устройство

- `atlas.html` — страница (вёрстка, стили, логика); `tools/build.sh` собирает из неё `index.html`.
- `data/` — подготовленные данные; `tools/prep.py` пересобирает их из исходников.
- `tools/pages.py` — текстовые страницы: страны, история, ресурсы, ветры и течения (запускается из `tools/build.sh`).
- `tools/content.js` — авторское содержание: войны, ресурсы, подписи течений и ветров. После правки: `node tools/content.js data`.
- `tools/names.py` — русские названия исторических государств и оценки их населения.
